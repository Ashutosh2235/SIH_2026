# Prototype test captures

Real PCAPs for testing the whole prototype (CLI, web UI, NetLens bridge), cut from the dataset's
**test split**. The risk model never saw these servers. Every constructed session lists the
findings it must produce in `expected.json`; sessions are identified by client IP (`198.18.x.y`).

Run them all, with pass/fail per session:

```bash
python -m securemailscope dataset check datasets/public-mail-tls/prototype-tests
```

Or by hand. The certificate cases need the dataset CA as the trust store, and `strip_remove` needs
the servers' history learned first:

```bash
python -m securemailscope analyze baseline-history.pcap --trust-store ../dataset-ca.pem --baseline-db b.sqlite -o r
python -m securemailscope analyze strip_remove.pcap --trust-store ../dataset-ca.pem --baseline-db b.sqlite --no-learn -o r
```

For a demo, `mixed-scenario.pcap` is self-contained: 50 history sessions plus one session of
every issue. Upload it to the web UI after starting it with the dataset CA:

```bash
python -m securemailscope serve --trust-store datasets/public-mail-tls/dataset-ca.pem
```
